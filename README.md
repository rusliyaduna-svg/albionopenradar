# Albion Open Radar

## Description
A helpful radar tool for the Albion Online community to track resources and events.

## Prerequisites
- Node.js (v14 or higher)
- npm (Node Package Manager)

## Installation Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/rusliyaduna-svg/albionopenradar.git
   cd albionopenradar
   ```
2. Install the dependencies:
   ```bash
   npm install
   ```

## Build Instructions
To build the project, run:
```bash
npm run build
```

## Usage
To start the application, run:
```bash
npm start
```
